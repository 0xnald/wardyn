# Wardyn

**Your positions never go unwatched.**

Built for Binance Agent OS Mini Hackathon — Track A.

Wardyn manages existing positions against a user-confirmed portfolio policy. The implementation is being developed in tested milestones: portfolio calculations, deterministic policies, demo scenarios, Binance adapters, monitoring, approvals, and decision receipts.

## Development

Requires Node.js 22+ and pnpm 11. Run `pnpm install`, then `pnpm dev`.

Checks: `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build`.

Demo execution is the default. No live trading is implemented in this foundation.
